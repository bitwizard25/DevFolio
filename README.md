# Next.js Project with Tailwind CSS and Geist Font

This project is a Next.js application bootstrapped with `create-next-app` that leverages Tailwind CSS for styling and the Geist font for seamless integration.

## Prerequisites

* Node.js (v16 or higher)
* npm (v8 or higher) or yarn (v1 or higher)

## Getting Started

### Development Server

To run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### File Structure

The project structure is as follows:

```
|- .gitignore         # Git ignore file
|- README.md          # This file
|- next.config.mjs     # Next.js configuration
|- package-lock.json   # Package lock file generated by npm or yarn
|- package.json        # Package manifest file
|- postcss.config.mjs  # PostCSS configuration
|- tailwind.config.ts  # Tailwind CSS configuration
|- tsconfig.json       # TypeScript configuration
```

## Tailwind CSS and Geist Font

This project utilizes Tailwind CSS for flexible styling and the Geist font for a unified and modern appearance. The `tailwind.config.ts` file contains the Tailwind configuration, while the `postcss.config.mjs` file sets up PostCSS to process CSS.

## Deployment on Vercel

To deploy your application to Vercel, follow the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying).
